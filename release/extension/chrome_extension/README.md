
# YouTube Video Interceptor

This Chrome extension intercepts clicks on YouTube video links and sends the captured URLs to a localhost helper.

## Installation

1. Open Google Chrome.
2. Go to `chrome://extensions/`.
3. Enable "Developer mode" using the toggle in the top right corner.
4. Click on "Load unpacked".
5. Select the `chrome_extension` folder created by this script.

## Usage

- The extension icon will show a popup with settings.
- You can enable/disable interception and change the helper URL.
